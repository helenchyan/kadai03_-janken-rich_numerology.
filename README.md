# 運命数

生年月日から、数秘術の「太陽（ライフパス）」を計算して、その数の性質を表示するWebアプリです。

G's ACADEMY TOKYO DEVコース 第32期（水金クラス）の課題として作りました。

## 使い方

1. 年・月・日をプルダウンから選ぶ
2. 「運命数を出す」を押す
3. 1〜9、11、22、33 のいずれかと、その数の性質が表示される

## 計算のしかた

生年月日を1桁ずつ足して、1桁になるまで繰り返します。

```
1991年4月17日
  1+9+9+1 = 20
  4       = 4
  1+7     = 8
  20+4+8  = 32
  3+2     = 5     →  太陽は 5
```

ただし **11・22・33 が出たら、そこで止めます。**
数秘でマスターナンバーと呼ばれる数で、1桁まで還元しません。

## 使った技術

- HTML / CSS
- JavaScript（変数・分岐・繰り返し）
- jQuery

## 工夫した点

- **年のプルダウンを `for` で自動生成。** 1930年から今年までを97個、手打ちせずに作っています。`new Date().getFullYear()` を使っているので、来年になれば自動で2027年まで出ます。
- **初期値を「今年 − 35」に設定。** 毎回1930年から延々スクロールしなくて済みます。
- **マスターナンバー（11・22・33）の判定を `if` で実装。** 普通は1桁になるまで足しますが、この3つだけは例外として止めます。
- **12種類の説明文はHTMLに持たせ、JavaScriptは表示の切り替えだけ。** 最初はJSに `if` を12個並べるつもりでしたが、文章を直すたびにJSを触るのが危ないのでやめました。JSは `hide()` と `show()` の2行です。
- **数字ごとに色を変えた。** 数秘では各数字に対応する色が決まっているので、それに合わせています。
- **結果が出るときにアニメーションを付けた。** 数字・説明・2つのボックスが少しずつ遅れて出ます。同時に全部出ると、どこを見ればいいか分からないためです。

## 難しかった点

- **クラス名を打ち間違えても、jQueryはエラーを出さずに黙っていること。** 「動かない」の原因がこれで3回ありました。`$(".button").length` が `0` なら名前が違う、と確認する習慣をつけました。
- **カッコを1つ閉じ忘れると、ファイル全体が1行も動かなくなること。** Prettier を入れて、保存して整形されなければ壊れている、と分かるようにしました。
- **`console.log` に式を直接書くと、実際に使われる値と違う値が出ること。** `Math.random()` は呼ぶたびに違う数を返すので、変数に入れてから出す必要があります。
